como funciona um algoritmo de ordenação

Counting Sort:

Imagine uma sala de correio com uma caixinha para cada número possível. Em vez de comparar cartas entre si, você só joga cada uma na sua caixinha e depois lê as caixinhas em ordem. É exatamente assim que o counting sort ordena.

O passo a passo

O truque do counting sort é nunca comparar dois elementos diretamente — ele só conta.

1

Descobrir o intervalo

Olha o menor e o maior valor do array para saber quantas caixinhas preparar.

2

Contar as ocorrências

Percorre o array original uma vez. Cada número visto soma +1 nas caixas correspondente ao seu valor.

3

Ler as caixinhas em ordem

Percorre as caixinhas do menor valor ao maior. Cada caixinha devolve seu valor tantas vezes quanto foi contado — e pronto, o array sai ordenado.

Em C++, passo a passo

A mesma lógica das caixinhas, escrita como uma função para cada passo.

passo 1 — descobrir o intervalo
struct Range { int minVal; int maxVal; int size; };

Range findRange(const vector<int>& arr) {
    int minVal = *min_element(arr.begin(), arr.end());
    int maxVal = *max_element(arr.begin(), arr.end());
    return { minVal, maxVal, maxVal - minVal + 1 };
}
passo 2 — contar as ocorrências
vector<int> countOccurrences(const vector<int>& arr,
                             int minVal, int rangeSize) {
    vector<int> count(rangeSize, 0);
    for (int num : arr) {
        count[num - minVal]++;
    }
    return count;
}
passo 3 — calcular a contagem acumulada
vector<int> calculateCumulativeCount(vector<int> count) {
    for (size_t i = 1; i < count.size(); i++) {
        count[i] += count[i - 1];
    }
    return count;
}
passo 4 — construir o array ordenado
// percorre de trás para frente para manter a estabilidade
vector<int> buildSortedOutput(const vector<int>& arr,
                              vector<int> count, int minVal) {
    vector<int> output(arr.size());
    for (int i = arr.size() - 1; i >= 0; i--) {
        int num = arr[i];
        output[count[num - minVal] - 1] = num;
        count[num - minVal]--;
    }
    return output;
}
tudo junto
vector<int> countingSort(const vector<int>& arr) {
    if (arr.empty()) return arr;

    Range r = findRange(arr);
    auto count      = countOccurrences(arr, r.minVal, r.size);
    auto cumulative = calculateCumulativeCount(count);
    return buildSortedOutput(arr, cumulative, r.minVal);
}
